What EcoFloat Does
Integrated System for
River Pollution Control
🤖

AI Trash Detection

YOLOv8 model running on Raspberry Pi detects floating litter and obstacles in real time at 6–10 fps using NCNN optimization.

🛰️

GPS Navigation

NEO-M8N GPS module tracks the drone's exact position on the river and logs the path for analysis on the live map.

📡

4G LTE Telemetry

Huawei E3372 LTE modem sends real-time data via MQTT over 4G, so the drone can be monitored from anywhere.

🗺️

Live Web Dashboard

Track the drone's position, motor status, battery, and all detection events on an interactive map dashboard.

⚙️

ESP32 Motor Control

ESP32 handles low-level brushless motor PWM control with Hobbywing SeaKing ESCs for precise water navigation.

📊

Analytics & Logging

All detection events, GPS paths, and telemetry are stored in MongoDB Atlas for historical analysis and reporting.
